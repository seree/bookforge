# Loop Engineering For Newbies

A complete BookForge example project — the full pipeline output, from research to finished HTML.

- **10 chapters**, casual voice, 1289–1396 words each (QA-gated)
- `agent` illustration theme (10 chapter spot illustrations + cover)
- 5 workflow diagrams: `agent-constrain`, `agent-meter`, `agent-context`, `agent-quadratic`, `agent-guard`
- **Open the book:** `loop-engineering-for-newbies.html` (single self-contained file)
- `bookforge.json` shows the manifest state; `chapters/` holds the source markdown.

(Research notes are intentionally not included in this example — they are fetched
third-party content and are regenerated by `bookforge research` on any machine.)
